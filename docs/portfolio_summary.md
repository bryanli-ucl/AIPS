# Portfolio Summary

AIPS is a dual-MCU autonomous indoor delivery robot built for structured indoor environments. It combines embedded C++ firmware, encoder-based motor feedback, IMU-assisted pitch stabilisation, IR line tracking, servo-mounted TF-Luna LiDAR obstacle detection, OLED feedback, and layered PID control.

The project demonstrates practical robotics engineering across sensing, actuation, control, communication, and system integration. The firmware is organised as a PlatformIO project with separate master and slave MCU environments, shared headers, hardware-focused documentation, utility scripts, and design diagrams.

## Highlights

- Designed a master/slave embedded architecture for distributed robot control.
- Implemented encoder feedback and PID-based motor control for differential drive motion.
- Integrated IMU feedback for pitch/orientation stabilisation.
- Used a QTRX reflective sensor array for line tracking.
- Added TF-Luna LiDAR scanning via servo control for obstacle detection.
- Built OLED-based status feedback for robot state visibility.
- Used I2C communication between controllers and peripherals.
